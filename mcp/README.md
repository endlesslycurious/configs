# MCP Servers

MCP servers connected via the `mcp` section of `opencode/opencode.jsonc`.

## GitHub

GitHub's official MCP server. Read repositories and code, manage issues and pull requests, and automate workflows through natural language.

<https://github.com/github/github-mcp-server>

## pdf-mcp

Lets agents work through large PDFs, or whole folders of them, without overflowing context: hybrid semantic and keyword search, selective page reading, tables, images, OCR, and chart extraction.

<https://github.com/jztan/pdf-mcp>

## paper-search

Searches, downloads, and reads academic papers across arXiv, PubMed, bioRxiv, CrossRef, Semantic Scholar, OpenAlex, and more, with open-access PDF fallback.

<https://github.com/openags/paper-search-mcp>

## Wikipedia

Retrieves factual information from Wikipedia to ground LLM responses: search, article summaries, sections, links, coordinates, and key facts.

<https://github.com/Rudra-ravi/wikipedia-mcp>
